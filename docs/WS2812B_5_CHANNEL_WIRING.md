# WS2812B 五通道穿戴燈接線

## 控制通道

ESP32-S3-N16R8 預設使用以下 GPIO。這些腳位避開 USB GPIO 19/20、BOOT GPIO 0、UART GPIO 43/44 與 OPI PSRAM 使用區域。

| 通道 | 部位 | GPIO | 邏輯燈位 | 實體 LED |
|---|---|---:|---:|---:|
| 1 | 帽子 | 4 | 60 | 60 |
| 2 | 右手 | 5 | 130 | 170 |
| 3 | 右腳 | 6 | 130 | 170 |
| 4 | 左腳 | 7 | 130 | 170 |
| 5 | 左手 | 15 | 130 | 170 |
| 合計 | | | 580 | 740 |

GPIO 可以在 Studio 的「LED 串聯」頁調整，但韌體只接受 GPIO 4 到 18（不含 19、20）及 GPIO 21。每個輸出不可使用相同 GPIO。

## DIN 與 DOUT

WS2812B 燈帶通常印有箭頭，箭頭就是資料方向：

```text
ESP32 GPIO -> 電平轉換 -> 330R -> DIN [LED -> LED -> LED] DOUT
                                      箭頭方向 ------------>
```

- `DI`、`DIN` 或箭頭尾端是資料輸入，接控制器或前一段的 `DOUT`。
- `DO`、`DOUT` 或箭頭尖端是資料輸出，只能接下一段的 `DIN`。
- 5V 與 GND 沒有資料方向，但必須確認正負極。
- 如果接反 DIN/DOUT，燈帶通常不會回應，但 5V 接反可能永久損壞燈帶。

第一次施工先只接一小段，在限流電源下執行開機紅、綠、藍自我測試，再擴充完整燈帶。

## 手指與腳趾並聯

每個四肢通道的資料順序如下：

```text
GPIO -> 去程 60 -> 五路資料分配器 -> 分支 1：10 顆 -> 終止
                               |-> 分支 2：10 顆 -> 終止
                               |-> 分支 3：10 顆 -> 終止
                               |-> 分支 4：10 顆 -> 終止
                               `-> 分支 5：10 顆 -> 回程 60 -> 終止
```

分支 5 預設為小拇指或小趾。五條分支的 DIN 接收相同資料，因此顯示相同效果。只將選定分支的 DOUT 接到回程燈帶；絕對不可將五個 DOUT 接在一起。

為降低長線與一分五造成的訊號反射，建議在手腕和腳踝使用 5V 邏輯資料分配器，例如以 `74HCT245` 或同級高速 5V buffer 將一個訊號分成五路。ESP32 的五個 3.3V GPIO 也應先經 `74AHCT125`、`74HCT245` 或同級元件轉成 5V 邏輯。

## 供電

740 顆 WS2812B 以每顆 60mA 保守估算，全白最大值約為：

```text
740 x 0.06A = 44.4A
5V x 44.4A = 222W
```

一般手機行動電源的 5V USB 輸出不適合直接供應整套服裝。韌體預設亮度限制為 25%，但電源與線材仍應依最壞情況保留安全餘量。

- ESP32 的 USB 或 5V 腳位不可承擔 LED 電流。
- 帽子與四肢應分區供電、分區保險，並在燈帶兩端或約每米注入 5V/GND。
- 所有電源負極、ESP32 GND、電平轉換器 GND 必須共地。
- 電池、降壓模組、接頭、線徑和保險絲須由實際持續電流與穿戴安全需求選定。
- 完整穿戴前，先以低亮度逐通道測試溫升、壓降、接頭鬆脫與續航時間。

## Studio 編排

「LED 串聯」頁可分別調整帽子、右手、右腳、左腳與左手。四肢可調去程、並聯數量、每支燈數、回程燈數及接續回程的分支。

Timeline 提供 BPM 與 1/4、1/8、1/16、1/32 拍格線。五指或五趾不需建立五份 Timeline clip；編排一個手或腳部位，並聯硬體會自動鏡像到五條分支。
